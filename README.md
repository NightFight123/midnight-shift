# midnight-shift

Makeshift shift board / midnight clock web app for Chromebook - simple `index.html`

## Live Site

Once GitHub Pages is enabled, visit:
**https://NightFight123.github.io/midnight-shift/**

## How to enable GitHub Pages (1 minute)

1. Go to the repository: https://github.com/NightFight123/midnight-shift
2. Click **Settings** (top menu)
3. In the left sidebar, click **Pages**
4. Under **Source**, select **Deploy from a branch**
5. Branch: **main**, Folder: **/ (root)**
6. Click **Save**

The site will be live in about 1 minute.

## Features

- Big digital clock with date
- Special message at midnight
- Notes / shift reminders that save in your browser (localStorage)
- Works offline after first load
- Perfect for Chromebook (just open the page or set as homepage)

## For Chromebook

Open the live URL in Chrome and pin the tab, or add to shelf for quick access. All data stays on your device.
